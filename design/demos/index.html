Aitist 首屏 · style 对比
粗草稿 · 定 style 用 · 数字与 trace 均为占位
A · Operator Console — 网站本身就是产品界面。深色、单一柠檬绿强调色（离开 shadcn 默认的 emerald， 同时把绿色还给「成功」状态）、全 mono 数据层、首屏右侧一段 agent trace 打字流出。 动的是数据，不是版式 —— 全站砍掉 fade-up，只留 opacity。 首屏后面那条 FLEET LIVE · 14 agents 要接真 fleet 数据，接不上就删掉，不编。
B · Instrument — 亮色瑞士技术风。骨白底 + 墨黑 + 工业橙，露出 12 栏网格， 01 / AITIST mono 标签压在细线上，巨型 tabular 数字。整个 AI 品类都是深色发光， 这个是唯一会被人截图问「谁做的」的方案。动效只有两种：细线自己画出来、数字 tabular 跳数。 代价 —— 真做要买 display 字体（Söhne Breit / GT Alpina 一类），这里先用 Archivo 顶着。
